### Task 1: /api/stt 加固 + whisper smoke-test

**Files:** Modify `app/api/stt/route.ts`

- [ ] **Step 1: smoke-test（真实网络，唯一允许）。** 用 `.env.local` 的 `OG_API_KEY`/`OG_API_BASE_URL` 直连 `POST {base}/audio/transcriptions`（whisper-large-v3），用一小段测试音频（可用 node 生成一个极短的静音/合成 wav，或 curl 一个已有样本）确认：(a) 忠实转写可用、返回 `{text}`；(b) 是否支持 `response_format: "verbose_json"` 且返回 segment/word confidence（决定 C3 的发音反馈是否可行）。结果写进 report。若无音频/网络，报 DONE_WITH_CONCERNS 并记录未验证。
- [ ] **Step 2: 加固 route。** `OG_API_KEY` 缺失 → 返回明确 `{ error: "STT not configured" }`（不再发 "Bearer undefined" → 502）；加显式请求体 size guard（如 ≤10MB，超限 413 明确错误）；language 保持可参数化（默认 en）；若 Step 1(b) 确认 verbose_json 可用，接受一个可选 `verbose` 参数返回 segment/confidence（供 C3），否则保持 `{text}`。保留"忠实转写不纠错"的 prompt。
- [ ] **Step 3:** `tsc` + `eslint app/api/stt/route.ts` 清。Commit `feat(stt): harden /api/stt (key precheck, size guard) + whisper smoke-test`.

### Task 2: `lib/speech.ts` 录音 + 转写 + 回退

**Files:** Create `lib/speech.ts`

**Interfaces:**
- Produces: `recordAndTranscribe()` — 返回一个可控录音会话。建议接口：
  ```ts
  export interface TranscribeResult { text: string; approximate: boolean; }
  export interface RecordingSession {
    stop(): Promise<TranscribeResult>; // stop recording → transcribe → result
    cancel(): void;
  }
  export const startRecording = async (): Promise<RecordingSession> => { ... }
  export const isRecordingSupported = (): boolean => { ... } // MediaRecorder || SpeechRecognition
  ```

- [ ] **Step 1: 写 `lib/speech.ts`。**
  - `startRecording()`: `await navigator.mediaDevices.getUserMedia({audio:true})` → new `MediaRecorder(stream)` → 收集 chunks；`getUserMedia` 拒绝 → throw 明确错误（`NotAllowedError` → "microphone permission denied"），不重试循环。
  - `stop()`: 停止 recorder、汇总 blob → `POST /api/stt`（multipart, audio blob）→ `{text, approximate:false}`；若 `/api/stt` 失败（网络/5xx/"STT not configured"）→ 回退：用 `SpeechRecognition` 对**同一段已录音无法重放**，故回退策略是——在 whisper 失败时提示用户"重说一次（近似识别）"并用 SpeechRecognition 现场识别，返回 `{text, approximate:true}`；或更简单：whisper 失败直接返回错误让调用方决定。**实现者按 c-consumers.md F 节的推荐选最简可靠方案，并在 report 说明**（关键是：whisper 成功 = 忠实转写；失败 = 明确降级 + approximate 标记，不静默）。
  - 停用时清理 stream tracks（`track.stop()`）避免 mic 常亮。
  - `isRecordingSupported()`: 检测 `MediaRecorder`/`getUserMedia` 或 `SpeechRecognition`。
- [ ] **Step 2:** `tsc` + `eslint lib/speech.ts` 清。推理核对：权限拒绝抛明确错误不循环；whisper 成功路径忠实转写；失败路径明确降级；stream 清理。
- [ ] **Step 3:** Commit `feat(lib): speech.ts — MediaRecorder → /api/stt with graceful fallback`.

## Phase 2 — TTS 兜底 awaitable（1 文件）

### Task 3: `lib/tts.ts` fallbackSpeak awaitable

**Files:** Modify `lib/tts.ts`

- [ ] **Step 1:** 现状：`fallbackSpeak` 调 `window.speechSynthesis.speak(utterance)` fire-and-forget，`speak()` catch 里同步调用后立即 resolve → 调用方（对话页 `speakAndResumeListening`）在兜底音频还在播时就重开 mic（回声回路根因）。改：`fallbackSpeak` 返回 `Promise<void>`，在 `utterance.onend`（及 `onerror`）resolve；`speak()` 的 catch 分支 `await fallbackSpeak(text, rate)`（把 rate 也应用到 `utterance.rate`——当前回退忽略 rate，Slow 失效）。这样无论 Edge TTS 成功还是回退，`speak()` 都在音频真正结束后才 resolve，互斥保证成立。
- [ ] **Step 2:** `tsc` + `eslint lib/tts.ts` 清。推理核对：回退路径 `speak()` 在 onend 后 resolve；rate 应用到 utterance。
- [ ] **Step 3:** Commit `fix(tts): fallbackSpeak returns awaitable promise (kills echo loop) + applies rate`.
